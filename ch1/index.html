第1章 计算机系统概述

本章是全书的开篇，目标是在动手拆解 CPU、存储器之前，先在脑子里装进一张「整机的地图」：计算机由什么组成、软硬件如何分工、程序是怎样一步步跑起来的，以及用什么指标衡量一台计算机快不快。初学时有些概念读不懂很正常，先混个脸熟，后面各章会反复回来把它们讲透。

本章小结

下表整理自教材本章小结，回答开篇的三个问题。

问题结论要点
主频较高的 CPU 一定比主频较低的 CPU 性能更高吗？ 不一定。CPU 性能受多种因素影响，不能仅凭主频高低判断优劣。主频表示 CPU 内部时钟信号的振荡频率，反映执行指令节拍的快慢，但并不直接等同于实际运行速度。实际性能还取决于微架构设计、流水线深度、缓存容量与层级、指令集效率、功耗、并行能力等。主频较低但微架构先进的 CPU，可能因更高的每周期指令数（IPC）而胜过主频更高但架构陈旧的处理器。
翻译程序、汇编程序、编译程序与解释程序有何区别？ 翻译程序是把一种编程语言转换为另一种语言的程序的总称，包括编译程序、解释程序和汇编程序。编译程序一次性全部翻译、生成可独立执行的文件；解释程序逐句翻译并立即执行、不生成目标程序；汇编程序专指把汇编语言源程序翻译为机器语言程序（详见下方常见问题 1）。
不同级别的语言所编写的程序有何差异？哪类语言可被硬件直接执行？ 机器语言由二进制指令构成，与硬件指令一一对应，可被 CPU 直接执行；汇编语言使用助记符，需经汇编后执行；高级语言更抽象，需编译或解释转换。只有机器语言能被硬件直接执行。

常见问题和易混淆知识点

问题 1翻译程序、解释程序、汇编程序、编译程序的区别和联系是什么？

翻译程序是将一种编程语言转换为另一种语言的程序，主要包括编译程序、解释程序和汇编程序。编译程序将高级语言源程序一次性全部翻译为目标程序（如机器码或汇编代码），生成可独立执行的文件，编译一次后无须重复翻译；解释程序逐条读取源程序语句，翻译成机器指令并立即执行，通常不生成可存储的目标程序，执行过程为「边翻译边执行」；汇编程序是一种特殊的翻译程序，将汇编语言源程序翻译为机器语言程序。

易混编译程序与汇编程序的区别只看源语言：源语言为高级语言（如 C、Java）、目标语言为低级语言（汇编语言或机器语言）的，称为编译程序；源语言为汇编语言、目标语言为机器语言的，称为汇编程序。

问题 2什么是透明性？透明性指什么都能看见吗？

恰好相反。在计算机领域，透明性指从某类用户的视角无法感知某一事物或属性的存在，与日常生活中的「透明 = 看得见」含义相反。例如，指令的格式、机器结构、数据指令格式等，对高级语言程序员是透明的（无须关心），而对汇编语言程序员则不是透明的。CPU 中的指令寄存器（IR）、存储器地址寄存器（MAR）和存储器数据寄存器（MDR）对所有程序员均透明。

问题 3计算机体系结构和计算机组成的区别和联系是什么？

体系结构指程序员可见的系统属性，包括指令集、数据类型、寻址方式等，属于抽象层面的定义；组成是体系结构的具体实现，涉及硬件如何完成取指、译码、执行等操作，包含大量对程序员透明的细节。例如，是否提供乘法指令属于体系结构问题，而采用何种电路（阵列乘法器还是移位相加）来实现属于组成问题。两台机器可以具有相同体系结构、不同组成方式，从而在性能和成本上差异显著。

问题 4基准程序执行得越快说明机器性能越好吗？

一般而言，基准程序的执行速度可以反映机器性能。但单一程序通常只覆盖特定工作负载，对计算、访存、I/O 等资源的需求各异，难以全面代表系统整体性能。
