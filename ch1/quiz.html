    第1章 习题精选

    考情本章为全书总览，选择题集中在两处：1.2 计算机系统层次结构（冯·诺依曼“存储程序”思想、层次结构排序、编译/解释/汇编的概念辨析，常直接考统考真题）与 1.3 计算机的性能指标（主频、时钟周期、CPI、MIPS/FLOPS 的概念辨析与计算，2010—2023 年真题反复命题）。综合题基本只考 1.3 的 CPI / MIPS / 主频综合计算。全部题目围绕一条主线：CPU 执行时间 = 指令数 × CPI × 时钟周期 及其各种变形，务必做到能默写、能互推。

    本页共 20 题：选择题 18 道（第 1～8 题出自 1.2 计算机系统层次结构，第 9～18 题出自 1.3 计算机的性能指标；做题本 1.1 节未配习题），综合题 2 道（做题本第 1 章综合题共 2 题，全部收录）。题干【 】内为做题本出处；选择题答案均已与《选择题【答案速查】》网格逐题核对。

    一、选择题（第1～18题）

    第1题【1.2·P9】完整的计算机系统应包括（　）

    1. 运算器、存储器、控制器
    2. 外部设备和主机
    3. 主机和应用程序
    4. 配套的硬件设备和软件系统
    答案与解析

    答案：D

    完整的计算机系统 = 硬件系统 + 软件系统，二者相辅相成、缺一不可。A 只是硬件中的运算部件和存储部件（主机核心）；B“外部设备 + 主机”仍只有硬件；C 缺少操作系统等系统软件，且未覆盖全部硬件。只有 D 同时包含配套的硬件与软件两大部分。

    第2题【1.2·P10】冯·诺依曼机工作方式的基本特点是（　）

    1. 程序一边被输入计算机一边被执行
    2. 程序直接从磁盘读到 CPU 执行
    3. 按地址访问指令并自动按序执行程序
    4. 程序自动执行而数据手工输入
    答案与解析

    答案：C

    冯·诺依曼机采用“存储程序”工作方式：指令和数据预先存入存储器，启动后控制器按地址访问指令、自动地逐条按序执行，故选 C。A 错，程序须先存入存储器再执行，不是“边输入边执行”；B 错，CPU 不能直接从磁盘取指令，程序须先调入主存；D 错，数据同样预先存放在存储器中，并非手工输入。

    第3题【1.2·P10】计算机系统采用层次化结构，从最上层的应用程序到最底层的硬件，其典型层次自上而下依次为（　）

    1. 高级语言虚拟机 → 操作系统虚拟机 → 汇编语言虚拟机 → 机器语言机器
    2. 高级语言虚拟机 → 汇编语言虚拟机 → 机器语言机器 → 操作系统虚拟机
    3. 高级语言虚拟机 → 汇编语言虚拟机 → 操作系统虚拟机 → 机器语言机器
    4. 操作系统虚拟机 → 高级语言虚拟机 → 汇编语言虚拟机 → 机器语言机器
    答案与解析

    答案：C

    典型层次自上而下为：高级语言虚拟机（M4）→ 汇编语言虚拟机（M3）→ 操作系统虚拟机（M2）→ 机器语言（传统）机器（M1）。即最上层是面向用户的高级语言层，向下依次为汇编语言层、操作系统层，最底层才是硬件直接识别的机器语言层。A 把操作系统层放到汇编语言层之上；B 把机器语言机器放到操作系统之上；D 把操作系统放到最高层，均不正确。

    第4题【1.2·P10】关于编译程序和解释程序，下列说法中错误的是（　）

    1. 编译程序和解释程序的作用都是将高级语言程序转换成机器语言程序
    2. 编译程序编译时间较长，运行速度较快
    3. 解释程序方法较简单，运行速度也较快
    4. 解释程序将源程序翻译成机器语言，并且翻译一条以后，立即执行这条语句
    答案与解析

    答案：C

    解释程序逐条“边翻译边执行”、不生成完整目标程序，因此执行速度比编译方式慢，C 中“运行速度也较快”错误（前半句“方法较简单”是对的）。A 正确，二者都是高级语言到机器语言的翻译途径；B 正确，编译的一次性开销较大，但生成的目标程序可高速运行；D 正是解释执行方式的定义。

    第5题【1.2·P10】只有当程序执行时才将源程序翻译成机器语言，并且一次只能翻译一行语句，边翻译边执行的是（　）程序；把汇编语言源程序转变为机器语言程序的过程是（　）。
    I. 编译　　II. 目标　　III. 汇编　　IV. 解释

    1. I、II
    2. IV、II
    3. IV、I
    4. IV、III
    答案与解析

    答案：D

    第一空：执行时才翻译、一次一行、边翻译边执行，是“解释”（IV）；第二空：把汇编语言源程序翻译成机器语言程序的过程称为“汇编”（III）。故选 IV、III，即 D。“编译”（I）是执行前一次性整体翻译，与第一空不符；“目标”（II）指翻译得到的目标程序，不是一种翻译过程。

    第6题【1.2·P10·2015 统考真题】计算机硬件能够直接执行的是（　）
    I. 机器语言程序　　II. 汇编语言程序　　III. 硬件描述语言程序

    1. 仅 I
    2. 仅 I、II
    3. 仅 I、III
    4. I、II、III
    答案与解析

    答案：A

    计算机硬件只能直接识别、执行机器语言（二进制指令）程序。汇编语言程序必须先经汇编程序翻译成机器语言程序才能执行，II 错；硬件描述语言（如 Verilog/VHDL）用于描述和设计硬件电路本身，并不是硬件可直接运行的程序，III 错。故仅 I 正确，选 A。

    第7题【1.2·P11·2019 统考真题】下列关于冯·诺依曼计算机基本思想的叙述中，错误的是（　）

    1. 程序的功能都通过中央处理器执行指令实现
    2. 指令和数据都用二进制表示，形式上无差别
    3. 指令按地址访问，数据都在指令中直接给出
    4. 程序执行前，指令和数据需预先存放在存储器中
    答案与解析

    答案：C

    C 错误：指令按地址访问没有问题，但数据并非“都在指令中直接给出”——操作数通常存放在存储器或寄存器中，由指令的地址码字段给出其所在位置，只有立即寻址时数据才直接写在指令里。A、B、D 均为“存储程序”思想的标准表述：程序的功能由 CPU 执行指令实现；指令和数据都以二进制表示、形式上无差别；程序执行前指令和数据须预先存入存储器。

    第8题【1.2·P11·2022 统考真题】将高级语言源程序转换为可执行目标文件的主要过程是（　）

    1. 预处理 → 编译 → 汇编 → 链接
    2. 预处理 → 汇编 → 编译 → 链接
    3. 预处理 → 编译 → 链接 → 汇编
    4. 预处理 → 汇编 → 链接 → 编译
    答案与解析

    答案：A

    以 GCC 编译流程为例：① 预处理：展开头文件、宏替换，得 .i 文件；② 编译：把预处理后的源程序翻译成汇编语言程序，得 .s 文件；③ 汇编：把汇编语言程序翻译成机器语言指令，得 .o 可重定位目标文件；④ 链接：把多个目标模块与库函数合并，生成可执行目标文件。顺序固定为“预处理 → 编译 → 汇编 → 链接”，选 A。

    第9题【1.3·P15】关于 CPU 主频、CPI、MIPS、MFLOPS，说法正确的是（　）

    1. CPU 主频是指 CPU 系统执行指令的频率，CPI 是执行一条指令平均使用的频率
    2. CPI 是执行一条指令平均使用 CPU 时钟的个数，MIPS 描述一条 CPU 指令平均使用的 CPU 时钟周期数
    3. MIPS 是描述 CPU 执行指令的频率，MFLOPS 是计算机系统的浮点数指令
    4. CPU 主频指 CPU 使用的时钟频率，CPI 是执行一条指令平均使用的 CPU 时钟周期数
    答案与解析

    答案：D

    D 正确：主频即 CPU 的时钟频率；CPI（Cycles Per Instruction）= 执行一条指令所需的平均时钟周期数。A 错：主频不是“执行指令的频率”，CPI 是周期数而非频率；B 错：MIPS（每秒百万条指令数）是指令执行速度指标，不是“一条指令平均使用的周期数”（那正是 CPI 的定义）；C 错：MFLOPS（每秒百万次浮点运算数）是浮点运算速度指标，不是“浮点数指令”本身。

    第10题【1.3·P16】计算机中，CPU 的 CPI 与下列（　）因素无关。

    1. 时钟频率
    2. 系统结构
    3. 指令集
    4. 计算机组织
    答案与解析

    答案：A

    \( \text{CPI} = \frac{\text{程序总时钟周期数}}{\text{程序指令总数}} \)，它取决于执行各类指令各需要多少个时钟周期，因而由指令集（指令功能、格式）、系统结构和计算机组织（如实现方式、是否流水）决定；而时钟频率（主频）只决定“一个时钟周期有多长”，不改变执行一条指令需要多少个周期，故 CPI 与 A 无关。

    第11题【1.3·P16】机器 A 的主频为 800MHz，某程序在 A 上运行需要 12s。现在硬件设计人员想设计机器 B，希望该程序在 B 上的运行时间能缩短为 8s，使用新技术后可使 B 的主频大幅度提高，但在 B 上运行该程序所需的时钟周期数为在 A 上的 1.5 倍。则机器 B 的主频至少应为（　）

    1. 800MHz
    2. 1.2GHz
    3. 1.5GHz
    4. 1.8GHz
    答案与解析

    答案：D

    ① A 机的总时钟周期数：\(N_A = f_A \times t_A = 800 \times 10^6 \,\text{Hz} \times 12\,\text{s} = 9.6\times10^{9}\) 个；
    ② B 机周期数为 A 的 1.5 倍：\(N_B = 1.5 \times 9.6\times10^{9} = 1.44\times10^{10}\) 个；
    ③ 要求 8s 内跑完：\(f_B = \dfrac{N_B}{t_B} = \dfrac{1.44\times10^{10}}{8\,\text{s}} = 1.8\times10^{9}\,\text{Hz} = 1.8\,\text{GHz}\)。
    故至少 1.8GHz，选 D。

    第12题【1.3·P16】假定编译器对高级语言的某条语句可以编译生成两种不同的指令序列，A、B 和 C 三类指令的 CPI 和两种不同序列所含的三类指令条数如下表所示，两个指令序列都在时钟周期为 2ns 的机器上运行，则下列结论中正确的是（　）

    指令类型CPI序列一的指令条数序列二的指令条数
    A112
    B211
    C342
    1. 序列一的 MIPS 数比序列二多 50，序列一的执行速度比序列二快 10ns
    2. 序列一的 MIPS 数比序列二多 50，序列二的执行速度比序列一快 10ns
    3. 序列二的 MIPS 数比序列一多 50，序列一的执行速度比序列二快 10ns
    4. 序列二的 MIPS 数比序列一多 50，序列二的执行速度比序列一快 10ns
    答案与解析

    答案：D

    ① 序列一：总时钟周期数 = \(1\times1 + 2\times1 + 3\times4 = 15\) 个；执行时间 = \(15 \times 2\,\text{ns} = 30\,\text{ns}\)；指令总数 = \(1+1+4 = 6\) 条；\( \text{MIPS}_1 = \dfrac{6}{30\times10^{-9}\,\text{s} \times 10^{6}} = 200 \)。

    ② 序列二：总时钟周期数 = \(1\times2 + 2\times1 + 3\times2 = 10\) 个；执行时间 = \(10 \times 2\,\text{ns} = 20\,\text{ns}\)；指令总数 = \(2+1+2 = 5\) 条；\( \text{MIPS}_2 = \dfrac{5}{20\times10^{-9}\,\text{s} \times 10^{6}} = 250 \)。

    ③ 比较：MIPS 上序列二比序列一多 \(250 - 200 = 50\)；时间上序列二比序列一快 \(30 - 20 = 10\,\text{ns}\)。选 D。

    第13题【1.3·P16】用一台 40MHz 的 CPU 执行标准测试程序，共包含 100 条指令，它所包含的指令混合比和不同指令的 CPI 见下表。该段程序的平均 CPI 和程序的执行时间分别为（　）

    指令类型CPI指令混合比
    算术和逻辑160%
    高速缓存命中的访存218%
    转移412%
    高速缓存失效的访存810%
    1. 2.26，\(5.6\times10^{-8}\,\mathrm{s}\)
    2. 2.26，\(5.6\times10^{-6}\,\mathrm{s}\)
    3. 2.24，\(5.6\times10^{-6}\,\mathrm{s}\)
    4. 2.24，\(5.6\times10^{-8}\,\mathrm{s}\)
    答案与解析

    答案：C

    ① 平均 CPI = \( \sum (\text{CPI}_i \times F_i) = 1\times60\% + 2\times18\% + 4\times12\% + 8\times10\% = 0.60 + 0.36 + 0.48 + 0.80 = 2.24 \)；
    ② 时钟周期 = \( \dfrac{1}{f} = \dfrac{1}{40\times10^{6}\,\text{Hz}} = 25\,\text{ns} \)；
    ③ 执行时间 = 指令条数 × CPI × 时钟周期 = \(100 \times 2.24 \times 25\,\text{ns} = 5600\,\text{ns} = 5.6\times10^{-6}\,\text{s}\)。
    故选 C。（若把平均 CPI 误算成 2.26，就会错选 A 或 B。）

    第14题【1.3·P17·2012 统考真题】假定基准程序 A 在某计算机上的运行时间为 100s，其中 90s 为 CPU 时间，其余为 I/O 时间。若 CPU 速度提高 50%，I/O 速度不变，则运行基准程序 A 所耗费的时间是（　）

    1. 55s
    2. 60s
    3. 65s
    4. 70s
    答案与解析

    答案：D

    I/O 时间 = \(100 - 90 = 10\,\text{s}\)。CPU 速度提高 50%，即速度变为原来的 1.5 倍，CPU 时间按反比缩短：新 CPU 时间 = \( \dfrac{90}{1.5} = 60\,\text{s} \)。I/O 速度不变，I/O 时间仍为 10s。总时间 = \(60 + 10 = 70\,\text{s}\)，选 D。（注意：提高的是“速度”，不能把 90s 直接乘 0.5。）

    第15题【1.3·P17·2013 统考真题】某计算机的主频为 1.2GHz，其指令分为 4 类，它们在基准程序中所占比例及 CPI 如下表所示。该机的 MIPS 数是（　）

    指令类型所占比例CPI
    A50%2
    B20%3
    C10%4
    D20%5
    1. 100
    2. 200
    3. 400
    4. 600
    答案与解析

    答案：C

    ① 平均 CPI = \( 2\times50\% + 3\times20\% + 4\times10\% + 5\times20\% = 1.0 + 0.6 + 0.4 + 1.0 = 3.0 \)；
    ② \( \text{MIPS} = \dfrac{\text{主频}}{\text{CPI} \times 10^{6}} = \dfrac{1.2\times10^{9}}{3.0 \times 10^{6}} = 400 \)。
    故选 C。

    第16题【1.3·P17·2014 统考真题】程序 P 在机器 M 上的执行时间是 20s，编译优化后，P 执行的指令数减少到原来的 70%，而 CPI 增加到原来的 1.2 倍，则 P 在 M 上的执行时间是（　）

    1. 8.4s
    2. 11.7s
    3. 14s
    4. 16.8s
    答案与解析

    答案：D

    执行时间 = 指令数 × CPI × 时钟周期。优化前后时钟周期（主频）不变，执行时间之比 = 指令数之比 × CPI 之比：\( t_{新} = 20\,\text{s} \times 0.7 \times 1.2 = 16.8\,\text{s} \)，选 D。

    第17题【1.3·P17·2017 统考真题】假定计算机 M1 和 M2 具有相同的指令集体系结构（ISA），主频分别为 1.5GHz 和 1.2GHz。在 M1 和 M2 上运行某基准程序 P，平均 CPI 分别为 2 和 1，则程序 P 在 M1 和 M2 上运行时间的比值是（　）

    1. 0.4
    2. 0.625
    3. 1.6
    4. 2.5
    答案与解析

    答案：C

    同一 ISA、同一程序 P，指令数 \(N\) 相同。\( t = N \times \text{CPI} \times \dfrac{1}{f} \)，故
    \( \dfrac{t_1}{t_2} = \dfrac{N \times 2 / 1.5\,\text{GHz}}{N \times 1 / 1.2\,\text{GHz}} = \dfrac{2}{1.5} \times \dfrac{1.2}{1} = \dfrac{2.4}{1.5} = 1.6 \)。
    虽然主频 M1 更高，但 CPI 大一倍，反而更慢，选 C。

    第18题【1.3·P17·2022 统考真题】某计算机主频为 1GHz，程序 P 运行过程中，共执行了 10000 条指令，其中 80% 的指令执行平均需 1 个时钟周期，20% 的指令执行平均需 10 个时钟周期。程序 P 的平均 CPI 和 CPU 执行时间分别是（　）

    1. 2.8，28μs
    2. 28，28μs
    3. 2.8，28ms
    4. 28，28ms
    答案与解析

    答案：A

    ① 平均 CPI = \( 1\times80\% + 10\times20\% = 0.8 + 2.0 = 2.8 \)；
    ② 时钟周期 = \( \dfrac{1}{1\times10^{9}\,\text{Hz}} = 1\,\text{ns} \)；CPU 执行时间 = 指令数 × CPI × 时钟周期 = \( 10000 \times 2.8 \times 1\,\text{ns} = 28000\,\text{ns} = 2.8\times10^{-5}\,\text{s} = 28\,\mu\text{s} \)。
    故选 A。

    二、综合题（第19～20题）

    第19题【P17】微机 A 和 B 是采用不同主频的 CPU 芯片，片内逻辑电路完全相同。

    1. 若 A 机的 CPU 主频为 8MHz，B 机为 12MHz，则 A 机的 CPU 时钟周期为多少？
    2. 若 A 机的平均指令执行速度为 0.4MIPS，则 A 机的平均指令周期为多少？
    3. B 机的平均指令执行速度为多少？
    答案与解析

    1. 时钟周期 = \( \dfrac{1}{\text{主频}} = \dfrac{1}{8\times10^{6}\,\text{Hz}} = 0.125\times10^{-6}\,\text{s} = 125\,\text{ns} \)。

    2. 平均指令执行速度 0.4MIPS = \(0.4\times10^{6}\) 条/s，平均指令周期为每条指令平均耗时：
      \( T_{指令} = \dfrac{1}{0.4\times10^{6}}\,\text{s} = 2.5\times10^{-6}\,\text{s} = 2.5\,\mu\text{s} \)。

    3. 片内逻辑电路完全相同 → 每条指令所需的时钟周期数（CPI）相同。
      A 机 CPI = \( \dfrac{\text{平均指令周期}}{\text{时钟周期}} = \dfrac{2.5\,\mu\text{s}}{0.125\,\mu\text{s}} = 20 \)；
      B 机时钟周期 = \( \dfrac{1}{12\times10^{6}\,\text{Hz}} = \dfrac{1}{12}\,\mu\text{s} \approx 0.083\,\mu\text{s} \)；
      B 机平均指令周期 = \( 20 \times \dfrac{1}{12}\,\mu\text{s} = \dfrac{5}{3}\,\mu\text{s} \approx 1.67\,\mu\text{s} \)；
      B 机平均指令执行速度 = \( \dfrac{1}{5/3\,\mu\text{s}} = 0.6\times10^{6} \) 条/s = 0.6MIPS。

      验算：CPI 相同时执行速度与主频成正比，\(0.4\,\text{MIPS} \times \dfrac{12}{8} = 0.6\,\text{MIPS}\)，结果一致。

    第20题【P17】某台计算机只有 LOAD/STORE 指令能对存储器进行读/写操作，其他指令只对寄存器进行操作。根据程序跟踪试验结果，已知每条指令所占的比例及 CPI 数如下表所示。

    指令类型指令所占比例CPI
    算术逻辑指令43%1
    LOAD 指令21%2
    STORE 指令12%2
    转移指令24%2
    1. 求上述情况下的平均 CPI。
    2. 假设程序由 M 条指令组成。算术逻辑运算中 25% 的指令的两个操作数中的一个已在寄存器中，另一个必须在算术逻辑指令执行前用 LOAD 指令从存储器中取到寄存器中。因此有人建议增加另一种算术逻辑指令，其特点是一个操作数取自寄存器，另一个操作数取自存储器，即寄存器-存储器类型，假设这种指令的 CPI 等于 2。同时，转移指令的 CPI 变为 3。求新指令系统的平均 CPI。
    答案与解析

    1. 平均 CPI = \( \sum (\text{CPI}_i \times F_i) = 1\times43\% + 2\times21\% + 2\times12\% + 2\times24\% = 0.43 + 0.42 + 0.24 + 0.48 = \mathbf{1.57} \)。

    2. 关键：改用新指令后，程序的指令构成也发生了变化（一部分前置 LOAD 被省掉）。设程序由 M 条指令组成：

      ① 算术逻辑指令 43%M 条中有 25% 改为寄存器-存储器型：\(0.43M \times 25\% = 0.1075M\) 条（CPI = 2）；其余 \(0.43M \times 75\% = 0.3225M\) 条仍为寄存器-寄存器型（CPI = 1）。

      ② 改型指令不再需要执行前取操作数的 LOAD，省掉的 LOAD = 0.1075M 条，LOAD 剩 \(0.21M - 0.1075M = 0.1025M\) 条（CPI = 2）。

      ③ STORE 不变：0.12M 条（CPI = 2）；转移指令 0.24M 条，CPI 变为 3。

      新指令总数 = \( (0.3225 + 0.1075 + 0.1025 + 0.12 + 0.24)M = 0.8925M \) 条；
      新总时钟周期数 = \( (0.3225\times1 + 0.1075\times2 + 0.1025\times2 + 0.12\times2 + 0.24\times3)M = (0.3225 + 0.215 + 0.205 + 0.24 + 0.72)M = 1.7025M \) 个。

      新平均 CPI = \( \dfrac{1.7025M}{0.8925M} \approx \mathbf{1.91} \)。

      对比原系统（1.57 → 1.91）：虽然指令总条数减少（0.8925M），但访存型算逻指令占比增大、转移指令 CPI 升到 3，平均每条指令的周期数反而上升。
