    第4章 指令系统

    指令系统是表征一台计算机性能的重要因素。本章要求掌握各种寻址方式的特点及有效地址的计算，三种偏移寻址（相对寻址、基址寻址和变址寻址）的地址计算方法，以及 CISC 与 RISC 的特点与区别。2022 大纲新增机器级相关内容，而机器级代码问题在历年真题中多次出现，需要熟练汇编代码的能力。本章知识点既可能直接用于解答有关指令的综合题，也可能结合其他章节出综合题。指令格式、机器指令、寻址方式与 CPU 指令执行过程密切相关，需重点掌握。

    408考纲要求
    • （一）指令格式的基本概念
    • （二）指令格式
    • （三）寻址方式
    • （四）数据的对齐和大/小端存放方式①
    • （五）CISC 和 RISC 的基本概念
    • （六）高级语言程序与机器级代码之间的对应②：编译器、汇编器与链接器的基本概念②；选择结构语句的机器级表示；循环结构语句的机器级表示；过程（函数）调用对应的机器级表示。

    ① 本考点在第 2 章的 2.3 节中介绍。② 本考点在第 1 章的 1.2 节中介绍。

    本章地图

    4.1 指令系统
    ISA 完整定义软硬件接口；指令 = 操作码 + 地址码，按地址码个数分零/一/二/三地址（各配访存次数）；定长操作码 \(2^n\) 条的算法与扩展操作码「前缀不重叠」的条数计算（15/15/15/16 与 15+12+63+16=106）；按功能分六类指令。
    4.2 指令的寻址方式
    指令寻址（顺序 / 跳跃）与数据寻址；形式地址 A 与有效地址 EA；十种数据寻址逐一拆解——隐含、立即、直接、间接、寄存器、寄存器间接、相对、基址、变址、堆栈，每种配有效地址公式、优缺点与典型例；表 4.1 汇总访存次数。
    4.3 程序的机器级代码表示
    x86 八个通用寄存器与常用汇编（mov/push/pop、add/sub、imul/idiv、逻辑与移位、jmp/j×/cmp/test、call/ret）；AT&T 与 Intel 格式差异；选择、循环（do-while / while / for）如何翻成 cmp + 条件转移；过程调用的栈帧、caller/callee 保存寄存器约定。
    4.4 CISC 和 RISC 的基本概念
    两条发展路线：CISC 增强指令功能（x86），RISC 简化指令系统（ARM、MIPS）；各自 7 条特点；表 4.3 十项对比（指令数目、字长、可访存指令、控制方式、流水线等）与「80%/20%」统计规律。

    本章小结

    下表整理自教材本章小结，回答开篇的三个思考题。

    问题结论要点
    什么是指令？什么是指令系统？为什么要引入指令系统？ 指令是控制计算机完成某种基本操作的命令。一台计算机所能执行的全部机器指令的集合，称为该机的指令系统。引入指令系统具有双重意义：对软件层面，它为程序员提供了统一的硬件操作接口，无须直接操作物理元件与二进制编码，显著提升了编程效率；对硬件层面，指令系统的格式、功能和寻址能力直接决定了处理器的架构设计、性能潜力和适用领域。
    一般来说，指令由哪些部分组成？各部分的作用是什么？ 一条典型指令由操作码和地址码两部分构成：操作码指明指令的功能类型（如加法、转移、加载等），是 CPU 识别和执行指令的核心依据；地址码提供操作所需的源操作数、目的操作数、运算结果的保存地址、程序转移的目标地址或子程序的入口地址等。通过操作码与地址码的组合，指令能够精确描述一次完整的运算或控制操作。
    对一个指令系统而言，寻址方式或多或少会带来什么影响？ 寻址方式的设置需权衡编程灵活性与硬件效率。寻址方式丰富（如立即数、寄存器、直接、间接、变址、相对等）可使程序编写简洁高效，便于表达复杂的数据访问模式，但会增加指令译码逻辑的复杂度，不利于流水线设计，并可能增大控制单元面积。寻址方式过少虽能简化硬件、提升执行速度，却会限制编程表达能力，迫使程序员用多条指令模拟复杂访问，降低代码效率。

    常见问题和易混淆知识点

    问题 1简述各种寻址方式的特点和适用情况

    • 立即寻址：操作数直接嵌入指令中，无须访存，常用于赋初值或常量；
    • 直接寻址：指令中给出操作数的内存地址，访存一次，适用于固定地址访问；
    • 间接寻址：指令给出地址的地址，需两次访存，扩大了寻址范围，易于完成子程序返回；
    • 寄存器寻址：操作数在寄存器中，指令短、速度快，适合高速运算；
    • 寄存器间接寻址：寄存器存放操作数地址，兼具灵活性与较大寻址范围；
    • 基址寻址：EA = 基址寄存器 + 偏移量，基址由系统设定，适用于多道程序的地址重定位；
    • 变址寻址：EA = 变址寄存器 + 偏移量，变址寄存器由用户控制，适合数组遍历和循环；
    • 相对寻址：EA = PC + 偏移量，主要用于转移指令。
    易混基址寻址和变址寻址的形式相同，都是 EA = 寄存器内容 + 偏移量，但基址寄存器由操作系统管理（面向系统，用于多道程序地址重定位），变址寄存器由用户控制（面向用户，用于数组遍历和循环）——谁的内容可变、归谁管，正好相反。

    问题 2一个操作数在内存可能占多个字节，怎样在指令中给出操作数的地址？

    现代计算机普遍采用字节编址，即每个内存单元存储 1 字节（8 位）。当操作数为多字节数据（如 int 占 4 字节、double 占 8 字节）时，指令仅给出该操作数的起始地址（第一个字节的地址），CPU 根据操作数类型自动读取连续的多个字节。

    问题 3采用 LOAD/STORE 型指令有什么特点？

    LOAD/STORE 是 RISC 指令系统的核心设计原则之一，其主要特点包括：

    • 访存与计算分离：只有 LOAD（从内存读入寄存器）和 STORE（从寄存器写入内存）指令能访问主存，所有运算指令（如加、减、移位）仅操作寄存器中的数据；
    • 指令格式规整：由于寄存器编号位数远少于内存地址，通过固定字段分配，可实现定长指令，极大简化译码逻辑；
    • 利于流水线执行：统一的指令长度和访存边界，使取指、译码、执行等阶段易于并行化；
    • 潜在缺点：频繁的数据搬运可能导致程序中 LOAD/STORE 指令比例较高，增加指令条数；但现代编译器优化和高速缓存机制可有效缓解此问题。
