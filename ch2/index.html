    第2章 数据的表示和运算

    本章内容较为繁杂，是全书公式密度最大的一章：计算机采用二进制表示数据，其表示与运算机制不同于日常使用的十进制。理解本章有助于掌握一套准确的规范，从历年连续考查 C 语言中 unsigned、short、int、long、float、double 等基本数据类型的表示范围、运算规则、溢出判断，以及类型转换、IEEE 754 浮点数的表示、特点与加减运算来看，本章均为考查重点，需要牢固掌握。好消息是：这些内容在 408 中几乎全部以选择题形式出现，拼的是熟练度和细心，把每个公式亲手演算几遍即可拿下。

    408考纲要求
    • （一）数制与编码：进位计数制及其相互转换；定点数的编码表示。
    • （二）运算方法和运算电路：基本运算部件——加法器、算术逻辑单元（ALU）；加减运算——补码加减运算、标志位的生成；乘除运算——乘除运算的基本原理、乘法电路和除法电路的基本结构。
    • （三）整数的表示与运算：无符号整数的表示和运算；有符号整数的表示和运算。
    • （四）浮点数的表示与运算：浮点数的表示；IEEE 754 标准；浮点数的加减运算。
    大纲变动教材中「原码一位乘法」「补码一位乘法（Booth 算法）」「除法的详细迭代流程」等传统手算乘除内容，考纲已降低要求——仅要求掌握乘除运算的基本原理、乘法电路和除法电路的基本结构。本站将相关手算细节标注为「选学·大纲已降低要求」，理解思想即可，不必背诵逐位流程。

    本章地图

    2.1 数制与编码
    进位计数制及其相互转换，原码、反码、补码、移码四种编码与表示范围，C 语言整型数据的截断与扩展。
    2.2 运算方法和运算电路
    全加器与 ALU 怎么搭，补码加减怎么做、溢出怎么判，标志位 ZF/OF/SF/CF 如何比较大小，乘除电路的基本结构。
    2.3 浮点数的表示与运算
    IEEE 754 的格式与特殊值，十进制 ↔ 浮点十六进制互转，浮点加减五步：对阶、尾数加减、规格化、舍入、溢出判断。

    本章小结

    下表整理自教材本章小结，回答开篇的四个问题。

    问题结论要点
    在计算机中，为什么要使用二进制来表示数据？ 原因有三：① 二进制只有两种状态，只需使用具有两种稳定物理状态的器件即可表示一位，硬件实现成本低；② 二进制的 1 和 0 恰好对应逻辑值「真」与「假」，为逻辑运算和条件判断提供直接支持；③ 运算规则极为简单，可通过基本逻辑门电路高效实现各类算术与逻辑操作。注意：十进制等进制也可借助编码进入机器（如 BCD 码），但物理存储层面一切数据都是二进制比特序列。
    计算机在字长足够的情况下能够精确地表示每个数吗？ 能：只要其数值在字长可表示的范围内，即可精确表示每个整数。但对于小数（实数），由于采用二进制表示，只能精确表示形如若干个 \(1/2^k\)（\(k\) 为正整数）之和的有理数。许多十进制有限小数在二进制下是无限循环小数，无法用有限位精确表示。例如，\(0.1 = (0.0001100110011\cdots)_2\)。因此，用十进制长度有限的字长下，这类数值也只能被近似表示。
    字长相同时，浮点数和定点数的表示范围与精度有什么区别？ 在相同字长下，浮点数与定点数存在「范围 vs 精度」的权衡：表示范围——浮点数通过阶码可表示极大或极小的数值，远大于定点数；表示精度——定点数将所有位用于数值本身，具有恒定且较高的相对精度，而浮点数需分配部分位给阶码，导致尾数位数减少、有效精度降低，且精度随数值增大而下降。因此，浮点数以牺牲精度换取更大的表示范围，定点数则以固定精度为代价限制其数值范围。
    用移码表示浮点数的阶码有什么好处？ IEEE 754 标准采用移码表示阶码，主要优势：① 便于阶码比较：浮点数加减运算时需要比较两个数的阶码大小，移码保持了真值的大小顺序，比较更方便；② 支持特殊性值的统一编码：阶码全 0，当尾数也为 0 时表示 ±0，尾数非零时表示非规格化数（用于渐进下溢）；阶码全 1，保留特殊用途——尾数为 0 时表示 ±∞，尾数非零时表示 NaN（如 0/0、∞−∞ 等无效运算结果）。

    常见问题和易混淆知识点

    问题 1如何表示一个数值数据？计算机中的数值数据都是二进制吗？

    在计算机内部，数值数据主要有两种表示方式：① 二进制数值表示：包括无符号数（如地址）、有符号数（通常用补码表示）和浮点数；② 二进制编码的十进制数（BCD 码）：用 4 位二进制编码一位十进制数。需要强调的是，所有数据在物理存储上都是二进制比特序列，区别仅在于解释规则。BCD 并非真正的「十进制表示」，而是按十进制语义解释的二进制编码。

    问题 2什么称为无符号整数的「溢出」？

    对于 \(n\) 位无符号整数，其表示范围为 0 到 \(2^n - 1\)。当运算结果大于或等于 \(2^n\) 时，硬件仅保留低 \(n\) 位（结果对 \(2^n\) 取模），舍弃高位，导致截断后的值不等于真实结果，这种现象称为无符号溢出。在运算器中，通常通过进位标志（CF）来检测无符号溢出。

    问题 3对于位数相同的定点数和浮点数，可表示的浮点数个数比定点数多吗？

    不是。\(n\) 位编码最多表示 \(2^n\) 个不同比特模式。定点数（如 \(n\) 位补码）通常能表示 \(2^n\) 个互异的有效数值；浮点数中，部分编码用于表示 ±0、±∞ 和 NaN 等特殊值，实际可表示的有效实数个数少于 \(2^n\)。因此，在相同位数下，定点数通常能表示更多有效数值。

    问题 4现代计算机中是否要求原码加减运算？如何实现？

    现代计算机一般不实现原码加减运算。尽管 IEEE 754 浮点数的尾数采用原码表示，但尾数本身是无符号的，符号由独立的符号位表示。在加减运算时，硬件根据操作数符号和运算类型，将尾数作为无符号整数送入通用运算器（如 ALU）进行加减运算，结果符号位由控制逻辑生成。因此，浮点尾数运算本质上是无符号整数运算，无须原码加减机制。

    易混本章三组高频易混点，复习时对照 2.1～2.3 各节：① 原码/反码/补码的转换——正数三种码相同；负数「原码取反加一得补码」（反码是中间态），符号位一律不变，补码表示范围比原码多一个最小负数；② 溢出判别——单符号位看「同号相加结果异号」，一位符号位看 \(C_n \oplus C_{n-1}\)，双符号位看两位是否相异；③ 浮点对阶——永远「小阶向大阶看齐」（尾数右移只丢低位，左移丢高位不可挽回）。
